# Snow Town

[Play Snow Town](https://heyitszackb.github.io/snow-town-play/)

A quiet procedural snow exploration game. Choose Follow mouse or Point and click in World controls. Follow mouse leads him with the cursor (hold and drag on touchscreens); Point and click walks to a clicked or tapped destination and stops. Shift-click to place the entity selected in the world controls.

This repository contains the published browser build. GitHub Pages serves the game directly from the main branch.
